# Code of Conduct

## Scope

This Code of Conduct applies to the GXNUTool project's Issues, Pull Requests, code reviews, discussion areas, instant messaging, and other collaboration scenarios surrounding this project.

GXNUTool is a campus-scenario tool project involving unified identity authentication, course schedule synchronization, and local credential storage. When participating in discussions, special attention should be paid to the privacy information in accounts, schedules, interfaces, and logs. Others' personal data or school system sensitive information should not be publicly disseminated.

## Basic Principles

Participants should follow these principles:

- Respect participants with different technical backgrounds, experience levels, and expression habits.
- Discuss around the issue itself; do not engage in personal attacks, mockery, humiliation, or malicious speculation.
- In code reviews, clearly point out issues, risks, and areas for improvement; avoid vague negations.
- Do not post arguments irrelevant to the project, advertisements, phishing links, malicious scripts, or illegal content.
- Do not disclose sensitive information such as real accounts, passwords, Cookies, Tokens, student IDs, names, or schedule screenshots on public channels.

## Unacceptable Behavior

The following behaviors may result in comment deletion, Issue locking, contribution rejection, or further participation restrictions:

- Insulting, threatening, harassing, discriminating against, or persistently provoking others.
- Deliberately submitting destructive code, malicious dependencies, hidden backdoors, or data theft logic.
- Publicly disseminating others' account information, login credentials, course schedules, communication captures, or other privacy data.
- Using project features to attack school systems, bypass access controls, or batch stress-test unauthorized interfaces.
- Continuing to deviate from the topic, repeatedly spamming, or creating useless arguments after being reminded.

## Feedback and Handling

If you discover behavior that violates this Code of Conduct, you can provide feedback through Issues, private contact with maintainers, or the reporting mechanisms provided by the GitHub platform. When providing feedback, please try to include:

- Relevant links or screenshots;
- Time of occurrence;
- Specific behaviors involved;
- Whether privacy or security risks are involved.

Maintainers will take measures based on the scope of impact, including reminders, editing or deleting content, closing discussions, rejecting merges, temporary or long-term participation restrictions, etc.

## Maintainer Responsibilities

Maintainers should strive to keep the handling process fair, restrained, and traceable. For issues involving privacy, security, or account data, priority should be given to reducing the risk of propagation before making public statements.
